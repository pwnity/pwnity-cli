> Summary: Information about the Workflow feature.

[bold]Workflow Automation[/bold]

The `workflow` command relates to the visual automation engine, a feature primarily designed for and available in the **pwnity PRO Web UI**.

The Web UI provides a powerful, node-based editor for designing, executing, and monitoring complex, multi-step automation workflows.

[bold]CLI Relevance[/bold]

The CLI commands associated with `workflow` (`add`, `list`, `destroy`) are considered legacy and have limited relevance for the core user workflow. The full power of this feature is unlocked through the graphical interface.

For detailed documentation on the available nodes and capabilities, please refer to the pwnity PRO documentation.
